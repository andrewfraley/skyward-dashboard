The theme button now opens a menu.

## What's changed

- **Pick the theme from a menu.** In 0.5.0 the theme button at the top right cycled through
  automatic, light and dark, one press at a time. It now opens a menu with all three, and a tick
  marks the one in use. *Automatic* still follows your device's setting and is the default. A
  choice you made in 0.5.0 is kept.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.5.1
```
