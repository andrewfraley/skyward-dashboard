A documentation update: the README now says which Skyward the dashboard works with.

## What's changed

- **Qmlativ only.** The dashboard works with Skyward Qmlativ Family Access, not the older Skyward
  SMS 2.0. The README explains how to tell which one your school uses from the address your
  browser shows after you sign in.

Nothing changes in the dashboard or the display.

## Upgrading

Nothing to do. If you want to be on the latest image anyway, `docker compose up -d` picks this up
if you have `pull_policy: always`; otherwise run `docker compose pull && docker compose up -d`.
