## What's changed

- **A theme button in the header.** The dashboard still follows your device's light or dark
  setting by default. The new button at the top right, next to *Update now*, switches between
  automatic, light and dark. Each browser remembers its own choice, so a phone and a laptop can
  differ. On phones the browser bar changes colour to match.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.5.0
```

Nothing to change in `.env`.
