A new API endpoint for small screens, ahead of support for battery e-paper displays.

## What's new

- **`GET /api/display`** returns everything a small display needs in one small response:
  for each student, the current grading period's grades (with classes at C- or below flagged),
  missing work this grading period, and what's due next, with due dates already worded
  ("Tomorrow", "3 days ago"). It also says when the last update was, whether it failed, and how
  long a battery display can sleep before the next scheduled update could bring anything new.
  A `hash` changes only when something on screen would, so a display can skip redrawing.
  Firmware for the Seeed reTerminal E1001 e-paper display that uses it is coming in a later
  release.

Nothing else changes in the dashboard.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.7.0
```
