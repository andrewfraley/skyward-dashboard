Syncs that go wrong now leave your dashboard as it was.

## What's changed

- **A bad sync no longer empties the dashboard.** If a sync comes back with nothing (no classes
  or no assignments for a student who had some), it's now reported as a failed sync and your
  last good data stays on screen. Before, it could wipe the dashboard while saying the sync
  worked, and the next good sync then listed every assignment as new. Between school years,
  when Skyward really has no classes, you'll see a failed sync until the new year's classes
  appear, with last year's data still shown.
- **Signing in to Skyward yourself mid-sync is handled.** Skyward allows one session per
  account. If you sign in on your browser while a sync is running, the sync now stops with a
  clear error instead of saving grades with their percentages missing.
- **Skyward's assignment filter is always put back.** The dashboard switches the Assignments
  page to *All Year* while it reads it, then back to *Current Term*. That switch back now
  happens even when the sync fails at the worst moment.
- **Your password stays out of the log**, including when a sync fails.
- **Small fixes.** A password in `.env` that starts or ends with a quote character is no longer
  cut short, and a damaged saved-session file is ignored instead of breaking every sync.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.5.3
```
