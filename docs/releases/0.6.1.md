Stronger privacy checks for the project itself. Nothing changes in the app.

## What's changed

- **The project's privacy checks are stricter.** The source code must never contain anything
  that identifies a family. The checks that guard this now also look at file names, binary
  files and commit messages, and at names and titles written the way web pages and data
  escape them (an apostrophe as `&#39;`, for example).
- **A test file is cleaned up.** Those stricter checks found one assignment title, from the
  developer's own data, that had been left in a test file; it's now a made-up stand-in. None of
  your data was ever part of the project: the dashboard only keeps your data on your own
  machine, in your `data` folder.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.6.1
```
