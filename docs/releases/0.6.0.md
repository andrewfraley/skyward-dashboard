Updates can only be started from the dashboard itself, and a wrong password no longer keeps
retrying.

## What's changed

- **Only the dashboard can start an update.** Before, any web page open in a browser on your
  network could quietly tell the dashboard to update from Skyward, over and over. Each update
  can sign you out of Skyward in your own browser. Update requests now need a header that other
  sites can't send.
- **"Update now" waits five minutes between updates.** Pressing it again sooner says when you
  can try again, instead of signing in to Skyward again.
- **A rejected password pauses automatic updates.** If Skyward turns down the sign-in, the
  dashboard stops trying on its schedule, since repeated wrong passwords can lock the account.
  Fix `SKYWARD_USER` / `SKYWARD_PASS` in `.env` and run `docker compose up -d`, or press
  *Update now* once it's fixed. Hovering over the update time says when updates are paused.
- **The page fills in after the very first update.** On a new install, the dashboard used to
  stay on "No data yet" after the first update finished, until you reloaded the page.
- **"Update now" shows its progress straight away**, and a refused update says why (already
  running, or too soon) instead of "Server unreachable".
- **Your data folder is private.** The database of grades is now readable only by the account
  the dashboard runs as, like the saved Skyward session next to it. Existing databases are
  changed on first start.
- **Easier with a screen reader or keyboard.** The "last update failed" icon now has a name
  screen readers announce, and you can tab to it to read why.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`.

**If you start updates from a script** (curl, Home Assistant, cron), add the header
`X-Requested-With: XMLHttpRequest` to its `POST /api/sync`, or it will get a 403:

```sh
curl -X POST -H 'X-Requested-With: XMLHttpRequest' http://localhost:8080/api/sync
```

To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.6.0
```
