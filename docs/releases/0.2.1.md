Groundwork for running Skyward Dashboard as a Home Assistant add-on. Nothing changes in the
dashboard, and there's nothing to do.

## What's changed

- **Each release now also updates a `stable` branch** in the repository, only after its image is
  published. A future Home Assistant add-on will follow that branch, so it never offers a version
  before the image for it exists.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.2.1
```
