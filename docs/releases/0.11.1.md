Nothing changes in the app itself. This release is for people who work on the code: development
now happens entirely on made-up demo data, so a child's real school records never have to sit
on a development machine.

## What's changed

- **Building from a checkout serves the demo data.** In a clone of the repo,
  `docker compose up -d --build` now runs the working tree against the invented demo student
  (`uv run python scripts/seed_demo.py` creates it) with the Skyward login left blank, so it
  never signs in and needs no `.env`. If you run your own dashboard from a checkout with that
  command, switch to the plain `docker-compose.yml` in a folder of its own, as the README
  describes.
- **DEVELOPING.md** describes the demo-data setup, and says that the tools which study the live
  Skyward site run only on the machine that runs the app.

## Upgrading

If you run the published image, nothing changes: `docker compose up -d` picks this up if you
have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. To stay
on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.11.1
```

Nothing changes in the display firmware.
