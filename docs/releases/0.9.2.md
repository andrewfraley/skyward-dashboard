A small update to the project page: a way to support the project.

## What's changed

- **Buy me a coffee.** If the dashboard is useful to you, there's now a
  [Buy Me a Coffee](https://buymeacoffee.com/andrewfraley) button at the top and bottom of the
  README, and a Sponsor button on the GitHub page.

Nothing changes in the dashboard or the display.

## Upgrading

Nothing to do. If you want to be on the latest image anyway, `docker compose up -d` picks this up
if you have `pull_policy: always`; otherwise run `docker compose pull && docker compose up -d`.
