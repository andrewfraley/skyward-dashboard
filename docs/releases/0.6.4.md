Small fixes: dates that stay current, and undated assignments in their place.

## What's changed

- **Dates stay current on a page left open.** If you leave the dashboard open overnight (on a
  tablet, say, or a pinned tab), "Tomorrow", "Due soon" and the current grading period now
  move on at midnight instead of waiting for the next update or a reload.
- **Assignments without a due date come last** in *Coming up*, instead of ahead of the ones
  due tomorrow.
- **One update at a time, however it's started.** Running an update by hand from the command
  line while the dashboard is updating now waits its turn instead of signing in to Skyward at
  the same moment.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.6.4
```
