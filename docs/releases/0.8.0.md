Firmware for a battery e-paper display, the Seeed reTerminal E1001, that shows the dashboard on a
shelf or a fridge.

## What's new

- **E-paper display.** Grades, missing work and what's coming up, for each student, on a
  7.5" black-and-white screen. It wakes only when your dashboard's schedule could have brought
  something new, redraws only when something changed, and sleeps in between. The buttons move
  between pages and students. [DISPLAY.md](https://github.com/andrewfraley/skyward-dashboard/blob/main/DISPLAY.md)
  covers the hardware, setup with ESPHome 2026.9.0 or later, and what everything on the screen
  means.

Nothing changes in the dashboard itself. The display reads `GET /api/display`, added in 0.7.0.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.8.0
```

To set up a display, follow DISPLAY.md. Its example config pins this release (`ref: v0.8.0`).
