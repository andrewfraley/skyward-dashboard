A round of fixes across the dashboard's pages.

## What's changed

- **Switching students shows the right student.** With more than one student on the account,
  switching quickly could briefly show the previous student's grades under the new name. The
  page now shows it's loading and only shows the student you picked. It also loads once at
  startup instead of twice.
- **The Overview tab works from a class page.** On a computer, clicking *Overview* while
  looking at a class did nothing; it now goes back.
- **Clearer Changes page.** A grading period's first grade reads "GP2 graded: B" instead of
  "GP2 grade changed: null → B". An error there clears once the page loads again, and the page
  shows it's loading instead of an empty box.
- **The right day on a class's grade trend.** The summary above the chart could name the next
  day for a change recorded in the evening; it now names the same day as the chart.
- **"Due in the next 7 days" counts 7 days**, today and the six after, not eight.
- **The "Classes at C- or below" tile** opens that class when there's just one, instead of
  linking to the page you're already on.
- **Small fixes.** Assignment lists start again at the top of the list when you change the
  filter, and show they're loading instead of nothing. A C- is flagged however Skyward writes
  it.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.6.2
```
