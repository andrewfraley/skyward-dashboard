Safer releases. Nothing changes in the app itself.

## What's changed

- **Only real releases reach you.** The build that publishes the image is stricter about when
  it moves `latest`: a hiccup while checking for an existing release, two updates landing at
  once, or a version number that goes backwards can no longer publish an image to everyone
  running `latest`.
- **Test builds have their own tags.** Images built from work in progress are now tagged
  `branch-<name>` instead of just `<name>`, so none of them can ever take the name of a release.
  If you were trying out a branch image, use the new tag.
- **The build tools are pinned.** The tools that build the published image are now locked to
  exact, checked versions, like everything else that goes into it.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.5.2
```
