Fixes for the new grading-period switch, and a round of accessibility fixes.

## What's changed

- **The grading-period switch covers every list.** On the Assignments page, *This grading
  period / All year* used to change only the Missing list; Upcoming, Graded and All kept showing
  the whole year. It now sits above the filters and applies to all of them, counts included.
- **You can tell which option is selected.** The selected filter used to be a slightly different
  grey, which was hard to see, especially in dark mode. It's now filled in and bold, and every
  option has a clear border.
- **Easier to read in dark mode.** Red text such as "Missing" was too faint on the dark
  background; dark mode uses a lighter red.
- **Better with a keyboard and a screen reader.** The grade trend chart and the rows-per-page
  menu show where the keyboard focus is, the category score bars are labelled, and the trend
  chart has a one-line summary above it.
- **Works with large text.** At bigger text sizes on a phone, the filters wrap onto a second row
  instead of running off the screen.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.4.1
```
