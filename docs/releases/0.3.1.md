A small fix to how some names are shown.

## What's changed

- **Single-letter parts of a name stay capitalised.** A teacher or class name ending in a single
  letter, like "TEACHER A", used to show as "Teacher a".
- The screenshots in the README now use obvious placeholder names ("Teacher A") for the made-up
  teachers.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.3.1
```
