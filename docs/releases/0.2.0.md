The dashboard now shows which version you're running.

## What's changed

- **A footer with the version number and a link to the project on GitHub**, at the bottom of
  every page. The version is the one the server is running, so it's the one to mention when
  reporting a problem.
- `GET /api/ping` now includes the running version too.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.2.0
```
