The dashboard now shows when the grading period ends, as the e-paper display already does. That's
the last day to hand in what's missing.

## What's changed

- **Grading period end date on the overview.** The "Missing in GP2" card says when the period
  ends and how long is left: "ends Wed, Nov 18 (in 30 days)". On a phone it sits on its own line
  under the heading. The Missing assignments count above the grades says it too.
- **The last week stands out.** In the period's final week, if anything is still missing, the
  date turns bold with a warning sign beside it, just as the display turns that corner black.
- Between grading periods, once the last one has ended, the date isn't shown.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.11.0
```

Nothing changes in the display firmware.
