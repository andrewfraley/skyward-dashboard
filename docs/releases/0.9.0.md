A new look for the e-paper display, with a countdown to the end of the grading period so you
know how long there is to hand in missing work.

## What's changed

- **Redesigned pages.** Each page has a large title and rounded cards, with the student and
  grading period in small type above. Grades sit in one card, with a struggling class's grade in
  a black pill and a "!" beside it. The missing count is still large and in black, so you can
  read it from across a room.
- **When the grading period ends.** Beside the Grades title: "Period ends Wed Oct 28 • 29 days
  left". In the period's last week, with anything still missing, the countdown turns black and
  gets a "!". The Missing page shows the end date too.
- **Coming Up is grouped by day**, under headings such as "Tomorrow" and "In 3 days".
- **Labels for the buttons.** Along the bottom, beside the page dots, each side names the page its
  white button goes to.
- **Restart from maintenance mode.** Let go of the green button, then hold it for 3 seconds: the
  display restarts as if just switched on.
- **The README describes the display**, with a screenshot, and DISPLAY.md has screenshots of all
  three pages.
- For people building their own display, `/api/display` gains `period_ends` and
  `period_days_left` for each student. Nothing was renamed or removed.

## Upgrading

Update the dashboard first: the countdown needs it. `docker compose up -d` picks this up if you
have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. To stay
on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.9.0
```

Then the display: change `ref:` to `v0.9.0` in your `skyward-display.yaml` and install it again,
over USB, or over Wi-Fi in maintenance mode (wake it with the green button and keep holding it
for 2 seconds). Until the dashboard is updated, the display shows the new design without the
countdown.

The display now redraws once a day even when no grades change, to keep the countdown right.
