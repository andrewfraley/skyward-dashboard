The dashboard's header now shows when it last updated and when something last changed, as times
instead of "2 hours ago".

## What's changed

- **Update and change times in the header.** It reads "Updated 2:00 PM · Last change 11:00 AM",
  with the day in front when it wasn't today ("Yesterday 9:00 PM", "Mon 6:00 PM"). Not every
  update finds something new, so the last change is often earlier than the last update; it's the
  same time the e-paper display shows.
- **On phones**, the header shows just the last change ("Changed 11:00 AM", or "Changed Mon"
  when it wasn't today) so the student's name keeps its room. Tap it for both times.
- `/api/status` gains `last_change`, the last update that found something new.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.10.0
```

Nothing changes in the display firmware.
