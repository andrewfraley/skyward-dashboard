Container hardening and a couple of documentation additions.

## What's changed

- **A tighter container.** After setting up your `data` folder, the dashboard drops to the
  `PUID`/`PGID` user in a way that can never gain back more rights, and fixing up folder
  ownership leaves anything a link points to alone.
- **Passwords with `$` in them.** The README now says to put such a password in single quotes
  in `.env` (`SKYWARD_PASS='pa$$word'`); Docker Compose otherwise reads `$word` as a variable
  and the sign-in fails.
- **`SKYWARD_LOG_LEVEL`** is now documented: `DEBUG` for more detail in `docker compose logs`,
  `WARNING` for less.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.6.3
```
