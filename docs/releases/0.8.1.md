Sharper text on the e-paper display.

## What's changed

- **Even letters on the display.** Some letters looked uneven on the panel, with one side of an
  "H" or "U" thinner than the other. Every font on the display now uses a size that draws its
  strokes a whole number of pixels wide, so letters look the same everywhere. Body text is a
  little larger and darker, which also reads better from across a room.
- The display's third page is now called **Coming up**, matching its heading.

Nothing changes in the dashboard itself.

## Upgrading

For the display, change `ref: v0.8.0` to `ref: v0.8.1` in your `skyward-display.yaml` and
install it again: over USB, or over Wi-Fi in maintenance mode (wake it with the green button and
keep holding it for 2 seconds).

For the dashboard, `docker compose up -d` picks this up if you have `pull_policy: always`.
Otherwise run `docker compose pull && docker compose up -d`. To stay on this release, set the
image line to:

```yaml
    image: afraley/skyward-dashboard:0.8.1
```
