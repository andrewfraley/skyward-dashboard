The dashboard now works properly on phones, and you can add it to your home screen.

## What's changed

- **A phone layout.** On a phone the pages are a tab bar along the bottom (the Assignments tab
  shows how many are missing), the header is one line that scrolls away, and nothing scrolls
  sideways any more.
- **Assignments as a list on phones and tablets**, one row each with the class, due date, score
  and grade, and missing work clearly marked. Tap **Show more** for the rest. On a wider screen
  it's still the sortable table.
- **Grades by category** on a class page stack neatly on a phone.
- **Add to home screen.** It opens full screen with its own icon, like an app. In Safari:
  **Share → Add to Home Screen**. In Chrome: **⋮ → Add to home screen** (or **Install app**).
- Nothing changes on a computer's browser.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.3.0
```
