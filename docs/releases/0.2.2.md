Fewer Skyward sign-ins, and no more "new sign-in" email for every update.

## What's changed

- **The app keeps its Skyward session between updates.** It used to sign in afresh every time,
  from what looked to Skyward like a brand-new device, so each update could send you a sign-in
  email. Now it reuses its session while Skyward keeps it open, and when it does have to sign in
  again, it does so as the same device it was before.
- The session is kept in `data/skyward-cookies.json`, readable only by the user the app runs as.
  Deleting it is harmless: the next update just signs in again.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. The first update after upgrading signs in once
more (it has no saved session yet); after that, sign-ins are the same device. To stay on this
release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.2.2
```
