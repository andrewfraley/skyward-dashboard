A behind-the-scenes release: nothing changes in the dashboard, and there's nothing to do.

## What's changed

- **Build hardening.** The tool used to build the image now comes from a source where every
  update waits a week before being proposed, like the rest of the app's dependencies. New
  releases of anything the app is built from are only picked up once they've been public for a
  while, which gives time for a bad release to be caught first.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.1.1
```
