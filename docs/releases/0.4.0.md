Missing assignments now count the same way Skyward does.

## What's changed

- **Missing counts cover the current grading period.** Skyward shows missing work for the
  grading period you're in, but the dashboard counted every missing assignment since the start of
  the year, so the two numbers didn't match. The overview, the class cards, the class page and
  the badge on the Assignments tab now count only the current grading period, and say how many
  more are missing from earlier in the year.
- **All year is one tap away.** On the Assignments page, the Missing filter has a new
  *This grading period / All year* switch.
- The overview says "in 1 class" instead of "across 1 classes".

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run
`docker compose pull && docker compose up -d`. To stay on this release, set the image line to:

```yaml
    image: afraley/skyward-dashboard:0.4.0
```
