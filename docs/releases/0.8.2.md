A lighter look for the e-paper display, with the missing count you can read from across a room.

## What's changed

- **A light header.** The display's header is now black on white with a rule under it, like the
  web dashboard, instead of a solid black bar. The overview's title is the student's name, as in
  "Demo's grades".
- **The header shows when something last changed**, with the time: "Last change Mon Sep 28,
  9:02 AM". It moves only when an update brings something new, so the display still skips
  redrawing when nothing did. This needs the dashboard at 0.8.2 too; with an older one the
  display shows the date of the last update, as before.
- **The LED stays on in maintenance mode**, so you can tell it's awake for an update.
- **Missing work stands out.** The number of missing assignments is shown large, in a black box
  at the top of the overview's right-hand column, followed by the assignments themselves. With
  nothing missing it says "All caught up".
- `dashboard_url` works with or without a slash at the end.
- The "Can't reach the dashboard", "Battery empty" and "Maintenance mode" screens use a size of
  their large text that draws more evenly.

Nothing changes in the dashboard itself.

## Upgrading

For the display, change `ref:` to `v0.8.2` in your `skyward-display.yaml` and install it again:
over USB, or over Wi-Fi in maintenance mode (wake it with the green button and keep holding it
for 2 seconds).

For the dashboard, `docker compose up -d` picks this up if you have `pull_policy: always`.
Otherwise run `docker compose pull && docker compose up -d`. To stay on this release, set the
image line to:

```yaml
    image: afraley/skyward-dashboard:0.8.2
```
